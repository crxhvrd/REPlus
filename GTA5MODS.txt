Rockstar Editor+
An overhaul of GTA V's Rockstar Editor. Legacy and Enhanced.


OVERVIEW

Rockstar Editor+ modifies the Rockstar Editor across the whole workflow:
camera interpolation, camera shake, export, and the editor's built-in limits.

It reimplements the editor's Smooth Blend, adds a procedural handheld shake,
and provides its own render pipeline behind the Export button. All settings are
exposed in the editor's existing marker menu. No external overlay, no separate
application.

Supported on both GTA5.exe (Legacy) and GTA5_Enhanced.exe (Enhanced). Single
build, no per-version download.


SMOOTH BLEND

Smooth Blend is the editor's own transition setting, and the one used for any
shot where the camera moves. Its stock implementation is a linear interpolation
between the two markers with a damped spring applied on top. Three consequences,
all familiar to anyone who has cut a clip in the editor:

- The path is a straight line. The camera cannot arc between markers, so any
  curved move has to be approximated with more markers.
- The spring trails its target, so the camera undershoots corners and does not
  arrive where the marker was placed.
- Speed is constant within a segment and steps at the boundary, so every
  keyframe lands with a visible kick.

Rockstar Editor+ replaces that implementation. Markers set to Smooth Blend
instead get:

- Position: a spline passing exactly through every marker.
- Rotation: interpolated across markers, continuous in rate.
- Field of view: monotone interpolation, no overshoot on a zoom.
- Speed: continuous across markers, so no velocity step at a keyframe.

Additional handling:

- Attached markers (camera mounted on a vehicle or ped) are interpolated in
  the parent entity's frame, then transformed by its live matrix.
- Look-at markers are re-solved from the splined camera position, so the
  target stays framed.
- Markers set to blend type None remain hard cuts. Linear markers are left
  alone by default and can be included with OnlySmoothBlend=0.

Per-marker overrides: curve tension, ease-in, ease-out, or reversion to stock
behaviour for a single segment.

Global options: curve shape (uniform / centripetal / chordal) and speed
profile (natural / continuous / per segment).


SHAKE

Procedural six-axis shake, configured per marker.

- Amplitude: degrees of rotation. Translation is derived at 0.05 m per degree.
- Frequency: hertz.
- Deterministic: a function of clip time, so playback and re-render produce
  identical output.
- Speed coupling: optional amplitude and frequency scaling with camera speed,
  and an optional gate that fades the shake out when the camera is stationary.
- Simple mode: amplitude and frequency only.
- Complex mode: two independent layers (sway, jitter), each with translation
  amplitude, rotation amplitude and rate, plus per-axis weights on all six
  degrees of freedom.
- Bulk apply: copy one marker's shake to every marker in the project.

Shake is evaluated against the clip timeline and is therefore static while the
playhead is paused.


RENDERING

Triggered by the editor's Export button. Disabled by default; set
EnableRenderer=1 in Render.ini.

- Output: video, or numbered PNG / JPEG sequence.
- No watermark.
- Motion blur: accumulated from real sub-frame renders. Default 64 samples,
  360 degree shutter. Both configurable.
- Frame rate: arbitrary, independent of playback rate.
- Audio: project audio is captured and muxed into video output.
- Scope: renders every clip in the project.
- Encoders: h264, h265, nvenc_hevc, prores_hq, lossless presets included.
  Arbitrary ffmpeg arguments accepted.
- ffmpeg is bundled. The bundled copy takes precedence over PATH.

Compatibility: the renderer takes over the editor's Export bake, which is the
same hook other export tools use. Those tools will not run while it is
enabled, and will not report an error. This is why it ships disabled. All
other features are additive.


EDITOR LIMITS

Enabled by default:

- Camera distance limit from the player removed (default cap 20000 m).
- Camera collision disabled - the camera passes through geometry, and the
  attach-entity push-off no longer displaces it from the authored path.
- Timeline scrub spinner suppressed.
- Social Club profanity check bypassed, so naming and exporting work offline.

Disabled by default:

- Zoom range extended beyond the stock 0.45x-4.50x. Configurable limits within
  the engine's own 1-130 degree FOV clamp.


REQUIREMENTS

- GTA V, Legacy or Enhanced. Singleplayer or FiveM.
- An ASI loader.

FiveM is supported. The same build serves both hosts - drop the files into
FiveM's plugins folder, with nothing to enable and no separate download. The mod
detects the host and starts differently there, but every feature behaves the
same. Note that FiveM refuses any plugin that does not declare the running game
build; the shipped build ids cover every version FiveM currently offers.

Rendering and depth-of-field sessions additionally require ReShade, installed
as the variant with FULL ADD-ON SUPPORT. The ordinary build cannot load add-ons
at all - the capture add-on is then ignored, and Export silently falls back to
the game's own watermarked encoder.

The capture add-on (IgcsConnector) and its depth-of-field shader are bundled.
They are needed because an ASI cannot read the GPU frame buffer directly.
ReShade itself is not bundled - it has its own installer and update cycle.

Smooth Blend, shake and the editor limits require only the ASI loader.


INSTALLATION

Extract into the game directory, beside GTA5.exe or GTA5_Enhanced.exe:

  <game>\RockstarEditorPlus.asi
  <game>\RockstarEditorPlus\                     settings, presets, ffmpeg
  <game>\IgcsConnector.addon64                  capture add-on
  <game>\reshade-shaders\Shaders\IgcsDof.fx    depth-of-field shader

No further setup. Configuration files are included rather than generated, so
the commented versions are present on first launch.


CONFIGURATION

In-game: the "Rockstar Editor+" row in any marker menu.

- Top-level marker menu: global settings, paged (Curve / Limits).
- Camera submenu: per-marker settings, grouped (Spline, Shake, Shake Motion,
  and four advanced shake pages).

Files, in <game>\RockstarEditorPlus\:

- RockstarEditorPlus.ini - camera, shake, editor limits.
- Render.ini - render and encoder settings.
- presets\ - one .ini per encoder preset.
- markers\ - per-marker settings, keyed by marker time.

Changes made in-game are written back automatically. Per-marker settings are
stored separately from the .clip file, so projects remain loadable without
this mod installed.


BEHAVIOUR NOTES

- Curve tension has no effect while the speed profile is Natural, the default.
  Natural derives the path from marker times and has no tension parameter.
  Set the speed profile to Continuous for tension to apply.

- A path that loops at a marker indicates the marker is positioned behind the
  approach rather than beside it. Any spline constrained to pass through every
  marker will double back if the marker sequence does.

- Diagnostics are available for both the curve and the shake, writing to
  RockstarEditorPlus\RockstarEditorPlus.log. Off by default.
